# 🎵 おんがくメーカー

音符を置いて自分で音楽を作れる Web アプリです。インストール不要で、パソコンでもスマホでも動きます。

GitHub Pages で公開すると `https://<ユーザー名>.github.io/github.io/` で開けます
（または `index.html` をブラウザで直接開いても使えます）。

## できること

### ✏️ 音符を置いて曲を作る（ピアノロール）
- ます目をタップ → 音符を置く / ドラッグ → 長さを変える / 音符をドラッグ → 移動 / 音符をタップ → 消す
- 全音符・2分・4分・8分・16分音符、付点、3連符
- 左の鍵盤をタップすると音を確かめられます
- トラック（パート）をいくつでも追加でき、楽器を選べます
  （ピアノ・エレピ・オルゴール・オルガン・ストリングス・ブラス・フルート・ギター・琴・ベース・8bit など）
- テンポ・拍子・調号・小節数を変更、くりかえし再生、元に戻す／やり直し
- スマホでは 2 本指でスクロール（または「✋ 移動」ツール）

### 🎼 楽譜表示
- 作った曲を五線譜（ト音記号・ヘ音記号の大譜表）で自動表示
- 印刷や SVG 画像での保存ができます

### 📚 テンプレート曲
| ジャンル | 曲 |
| --- | --- |
| クラシック | 歓喜の歌、エリーゼのために、アイネ・クライネ・ナハトムジーク、カノン、メヌエット ト長調、ブラームスの子守歌、家路（新世界より）、山の魔王の宮殿にて |
| 童謡・民謡 | きらきら星、さくらさくら、かえるの合唱（輪唱） |
| 季節・イベント | ジングルベル、きよしこの夜、ハッピーバースデー |
| アニメ・ゲーム風 | 青空スタートライン（アニメOP風）、はじまりの草原（RPG風）、夕焼けの約束（バラード風）、ほしふるステッキ（魔法少女風） |

> クラシック・童謡などは著作権の切れた（パブリックドメインの）曲だけを収録しています。
> 実在のアニメ・ゲーム曲は著作権があるため収録せず、代わりにこのアプリ用に作った**オリジナルの「アニメ風」曲**を入れています。
> 好きなアニメ曲は、MIDI / MusicXML ファイルや楽譜の画像を読み込んで楽しめます（個人で楽しむ範囲で）。

### 📷 楽譜を読み込む → 自動で音符が並ぶ
| 形式 | 精度 | メモ |
| --- | --- | --- |
| 画像（写真・スキャン・スクショ）、PDF | ○ | 五線・符頭・符尾・旗/連桁・付点・小節線を読み取り、音符を自動で配置。拍子と大譜表は自動判定。調号は選択。**休符・臨時記号・装飾記号は読み取りません**。読み取り結果は色つきの丸で表示され、まちがいはタップで除外できます |
| MusicXML（.musicxml / .mxl / .xml） | ◎ | MuseScore などから書き出せる形式。タイ・和音・複数パートにも対応 |
| MIDI（.mid） | ◎ | ドラム以外のトラックを読み込み |
| ABC 記譜法（.abc / テキスト貼り付け） | ◎ | 臨時記号・タイ・3連符・付点リズム・和音・複数声部に対応 |
| このアプリの保存ファイル（.json） | ◎ | |

画像の読み取りのコツ：
- 印刷されたきれいな楽譜ほどうまくいきます（手書きは苦手です）
- 楽譜がまっすぐ・画面いっぱいに写るように撮る（多少の傾きは自動で補正します）
- 複雑な楽譜は、[MuseScore](https://musescore.org/) や [Audiveris](https://audiveris.github.io/) で MusicXML に変換してから読み込むと正確です

### 💾 保存・書き出し
- ブラウザ内に保存（複数曲）、自動保存
- 保存ファイル（.json）、MIDI（.mid）で書き出し

## キーボードショートカット（パソコン）
| キー | 動作 |
| --- | --- |
| スペース | 再生 / 一時停止 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| 1〜5 | 音符の長さ（全・2分・4分・8分・16分） |

## ファイル構成
```
index.html          画面
css/style.css       デザイン
js/util.js          共通処理・かんたん楽譜記法
js/audio.js         シンセ音源と再生
js/templates.js     テンプレート曲
js/pianoroll.js     ピアノロール（音符エディター）
js/score.js         五線譜の描画
js/midi.js          MIDI 読み込み・書き出し
js/musicxml.js      MusicXML 読み込み
js/abc.js           ABC 記譜法の読み込み
js/omr.js           楽譜画像の読み取り（OMR）
js/app.js           アプリ本体
```
ビルド不要の素の HTML / CSS / JavaScript です。PDF の読み込み時だけ [pdf.js](https://mozilla.github.io/pdf.js/) を CDN から読み込みます。
